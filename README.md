## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/GoodNightMare/GoodNightMare.github.io.git
```

Navigate to the project:

```bash
cd GoodNightMare.github.io
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
